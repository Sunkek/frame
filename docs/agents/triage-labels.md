# Triage Labels

The skills speak in terms of five canonical triage roles. This file records the
label string this repo's issue tracker uses for each one.

| Role                     | Label             | Meaning                                  |
| ------------------------ | ----------------- | ---------------------------------------- |
| Needs maintainer triage  | `needs-triage`    | Maintainer needs to evaluate this issue  |
| Waiting on the reporter  | `needs-info`      | Waiting on reporter for more information |
| AFK-ready                | `ready-for-agent` | Fully specified, ready for an AFK agent  |
| Human-only               | `ready-for-human` | Requires human implementation            |
| Declined                 | `wontfix`         | Will not be actioned                     |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the
corresponding label string from this table.
